# Fasti benchmarks

Benchmark receipts are evidence bound to one source tree, contract set, artifact, runner, and custodian. A target in the README is not a passing result.

The first executable suite is the [B1 native and OCI baseline](b1/README.md). It measures complete process trees and, for OCI subjects, their complete cgroup-v2 boundary. It also keeps constrained-device qualification hypotheses explicit without assigning owners or results that do not exist.

No benchmark subtracts an empty-process baseline from Fasti's reported memory. The empty subjects expose runner and packaging overhead for comparison only.
