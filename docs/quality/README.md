# Quality evidence

This directory keeps acceptance records and exact-head evidence for high-risk
user flows. Each record states whether it is a pending specification or a
completed evidence record. A requirement is not a test result.

- [Account and browser-session UI acceptance record](auth-account-accessibility-evidence.md) — pending; no exact-head pass result recorded.
- [Documentation portal design audit](documentation-portal-design-audit.md) — local
  implementation verified; pull request and exact-head CI review pending.

These records support review and release decisions. They do not replace a
product-wide security assessment, WCAG conformance audit, EN 301 549 evaluation,
or platform assistive-technology test.
