## [Unreleased] (v0.1.0-alpha)

### Added
* Initial project governance, AGPL-3.0 licensing, and DCO 1.1 sign-off workflow.
* Complete monorepo workspace scaffolding supporting Rust (`crates/*`, `apps/fastid`) and TypeScript (`packages/*`, `apps/web`, `apps/desktop`).
* Brand guidelines and design system specifications adhering to W3C Design Tokens Community Group (DTCG 2025.10).
* Domain crate definitions: `fasti-core`, `fasti-activity`, `fasti-store`, `fasti-projections`, `fasti-sync`, `fasti-api`, `fasti-auth`, `fasti-player`, `fasti-connectors`, and `fasti-cli`.
* GitHub issue forms, PR review checklist, CODEOWNERS, and CI/CD security workflows.
