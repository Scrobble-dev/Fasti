# Fasti Web Client (`@fasti/web`)

The official web frontend for Fasti. Provides a responsive, accessible interface for viewing your media chronicle, managing playback queues, exploring history, and configuring node settings.

---

## Key Features
* **The Book of Days Timeline:** Chronological, publication-style timeline of all recorded media events.
* **Continue / Resume Queue:** Fast access to recently paused or ongoing books, episodes, films, and games.
* **Accessible Navigation:** Full keyboard navigation, screen reader landmarks, and 44px touch targets.
* **Offline Local Mode:** Retains state and queues mutations during temporary network disconnects.
